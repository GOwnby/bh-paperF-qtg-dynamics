# Event-horizon-regular data and the constrained evolution in QTG (Paper F, Sections 9-12)

Setup (once): `bash setup.sh` (gcc, numpy, scipy, matplotlib). It builds `../libqtg.so`, `paperE_inner_horizon/code/nonlinear/libdouble_null.so`, copies the data-construction modules of Paper E
(`paperE_inner_horizon/code/eh_init/*.py,*.c,*.npy`: dnU.py, dn2lib.py, kernel_lib.py, transfer.py, ...) into this directory and builds `libdouble_null.so`, `libstream.so`, `libstream2.so` here.
Regenerate everything: `bash run_eh.sh` (about 90 minutes on one core; the runs are independent). Environment: `QTG_CODE` (default `..`) is the directory with `qtg_lib.py`, `libqtg.so`.

New in `../qtg_dn.c` / `../qtg_lib.py`: `evolve_stream_qtg_cy` / `run_stream_cy(model,L2,row0,col0,hu,hv,cols,niter=3,y0=0.5,mode=3,rows=None)`, the constrained evolution
(y along u, q=-r_v/W along v, r from r_v; modes 1: project r_u only, 2: r_u and r_v, 3: also r). The original `evolve_stream_qtg` (free evolution) is unchanged.

| file | purpose |
|---|---|

| `dnU_qtg.py` | teleological horizon data (backward shooting), initial row, grid map `U=c(e^{kappa_+ s}-1)/kappa_+` for the QTG equations (`build_eh_q`) |
| `gen_q.py` | four-mesh run: `gen_q.py model L2 B k v1 h1 h2 ...` (env `MASS`), writes `genq_*.json` (eight fields on four rays, v=20..v1-2, every mesh) |
| `analyze_q.py` | Richardson-Romberg extrapolation in h^2 (grids coarse -> fine) and derived quantities; imported by the analysis scripts |
| `late_q.py`, `endpoint_q.py`, `front_q.py`, `width_q.py`, `plateau_q.py`, `kap_check.py`, `kap_check_b.py` | late-time tables, endpoint diagnostics, front time/width, metric-exponent plateau vs -kappa_-(m_f) |
| `kernel_ratio_q.py`, `cmp_add.py` | flux against the linear kernel of Paper G; QTG against the additive closure (reference runs `data/gen3_*.json`, Paper E's `gen3.py`) |
| `masslaw_q.py`, `curv_q.py`, `curv_terms_q.py`, `check_curv_static.py` | exact mass law on the extrapolated rays; Kretschmann invariant and its terms; check of the formula on static interiors |
| `t_static_cy.py` (env `MODE`), `t_static_free.py`, `t_static_q.py`, `t_static_b.py` (env `MASS`), `free_vs_con.py`, `check_ruv_q.py` | validation: exact static data (constrained / free evolution), bounded h, free vs constrained on tail data, residual of the unused r_uv equation |
| `profile_q.py`, `conv_curv.py` | profiles in U at fixed v; mesh dependence of the invariants (exploratory, not quoted) |
| `fig_eh.py` | figure of the paper (reads `data/` and `logs/`) |

`data/`: extrapolation inputs. `genq_m1_*` Hayward (B=3e-4, 3e-3, 3e-2; v1=110; B=3e-3, 3e-2 also v1=200), `genq_m2_a1_M1.5_*` bounded (alpha=1, m=1.5), `genq_m2_a1_B0.003_k1.5_v110.json` bounded m=5 (poorly resolved, not used), `gen3_*` additive-closure reference (Paper E pipeline).
`logs/`: every number quoted in Sections 9-12 of the paper (the file names are given there).

Status of the claims
1. Static data (B=0): constrained evolution (mode 3) second order, extrapolated error <= 4.7e-11 in r, sigma_v, psi up to v=98 (Hayward), 4.1e-11 (bounded, m=1.5); free evolution fails by v~60. Bounded m=5, alpha=1 (gap 5e-3 from the wall) is not resolved (error 6.5e-3): not used.
2. Linear flux = kernel of Paper G to 8e-4 (B<=3e-3); QTG - additive ~ -(27-41) B^2; B=3e-2 departs by 0.8-1.1 %.
3. Metric exponent = -kappa_-(m_f), m_f the generalized mass accumulated on H+: 2e-6 or better (Hayward), 5.5e-5 (bounded, B=3e-2, short plateau).
4. Window of the extrapolated solution (first non-finite point of the coarsest used level minus 30): with the isotropic four-mesh runs v<~170 (Hayward B=3e-3), ~90 (B=3e-2), >=108 (B=3e-4); bounded v<~95 (B=3e-4), ~60 (3e-3), ~40 (3e-2). With the anisotropic runs (h_s=0.05, h_v refined, `gen_q2.py`): B=3e-3 accurate to v=300, B=3e-4 and k=1/2 to ~290, k=3 to ~190, B=3e-2 to ~160, m=3 to ~170; bounded (B=3e-4) to ~125. The limit is a numerical error law, first non-finite v ~ 205.25+(2/kappa_+)ln(1.5e-4/(B h_v)) (`vb_law.py`), mechanism not derived.
5. The r_uv residual test is uninformative behind the front (r_uv ~ 1e-15, roundoff of the finite difference); mode 2 (r_uv equation) and mode 3 agree to 7.3e-9 in sigma_v (`modecmp.py`); the c3 term of sigma_uv (which dominates the curvature) is checked for compatibility in 80-digit arithmetic (`check_compat_pole.py`, 7e-50), its influence is measured (`c3_sensitivity.py`: +-10 % moves sigma_v(70) by ~0.025, c3=0 gives no front), and it is derived from the reduced action (item 8); its derivation is in item 8 and the evolution is checked by an independent code (item 10).
6. Slaving (`slaving_*.py`, `rho_check.py`, `slaving_pde.py`): phi_v u-independent to 3e-6, y*rho=beta exact, sigma_v = dln(rho)/dv to ~2e-4 (h_s=0.05 systematic -1.6e-4, `hs_extrap.py`), sigma_v ~ 2 dln|Phi|/dv (Phi = kernel flux of Paper G, `gpred_q.py`) to 2-3 %; m=3 (`slaving_pde_M3.log`) same structure, constant z*m = 0.677 vs 0.590.
7. Endpoint (`endpoint_table.py`, `ktable.py`, `mk_endtable.py`): sigma_v(300) = -0.0182, v*sigma_v -> -(2k+2) (-5 for k=3/2), K = 1.3e28 at v=300 (B=3e-3); beyond v~400 the statement sigma_v -> 0^- (no zero crossing, K -> v^(4k-2)) is a continuation using the kernel, not a simulation; code B (item 10) reaches v~380 for K: local slope 2.5 on 300<=v<=380, consistent with the slaved prediction 4-6 v0/(v-v0)+2(|v sigma_v|-5), v0~85.
8. Derivation from the action (`action_check.py`, `action_check2.py`, `action_check3.py`; logs `logs/action_check*.log`): the 2D Horndeski action of the spherical reduction (arXiv:2509.19016 Eqs. 22-26; arbitrary h in arXiv:2602.16773 Eq. 130) is differentiated automatically (exact rational Taylor jets, dual numbers) at random points. E_W = 0 is the r_uv equation, E_r = 0 (with the Raychaudhuri constraints) is the sigma_uv equation including the c3 term (exact zero difference in 12 tests with a_2 = 0, <= 1.3e-14 in 8 tests with a_2 != 0 where G_4 contains a logarithm); the action built from the static reduction N (r^3 h)' alone has identical Euler-Lagrange expressions; the Raychaudhuri coefficient c = 4 pi/h' is the only one for which the constraint propagates (30 exact tests; 1.1 c and c (1+psi/5) fail). Limits: the lifts of the 4D invariants are checked in item 11; the Hayward case rests on arXiv:2602.16773.
9. Not done: kernel for m=3 and bounded h; a code in another gauge (phi=r); derivation of the prefactor of the error law; timelike geodesics at v=infinity; hyperbolicity.

Anisotropic runs: `python3 gen_q2.py model L2 B k v1 hs:hv hs:hv ...` (env `MASS`) writes `genq2_hs<hs>_m<model>[_M<MASS>]_B<B>_k<k>_v<v1>.json`; `merge_levels.py` joins files with disjoint levels; run long jobs with `setsid nohup ... &`. New data: `data/genq2_*` (B=3e-3 merged, hs=0.025 control, B=3e-4, 3e-2, k=0.5, 3, MASS=3). New logs: `logs/g2_*.log` (run logs), `endpoint_*`, `slaving*`, `vb_law`, `hs_extrap`, `modecmp`, `c3_sensitivity`, `check_compat_pole`, `ktable`, `bounded_*`, `curv_hv*`, `gpred_final`.

10. Second implementation (`codeb/`, Paper F Sec. 'A second implementation'): `qtg_b.c` (method of lines, RK4 in v, RK4 along s with cubic interpolation, sigma_v and phi_v by integration along s from the horizon column; env/arg proj=1 recomputes y from the Raychaudhuri constraint, proj=0 evolves y by its ODE), `gen_b.py` (driver: `python3 gen_b.py model L2 B k v1 hs:hv ...`, env `PROJ`, `MASS`; build `gcc -O3 -shared -fPIC -o libqtgb.so qtg_b.c -lm` inside `codeb/`; needs `QTG_CODE` as above), `t_static_b4.py` (exact static test, order 4.00), `cmp_hs.py` (h_s convergence), `cmp_AB_final.py` and `cmp_table.py` (code A vs code B, first non-finite v), `kstudy.py` (K, its terms and slopes), `tidal.py` (affine distance, transverse tidal eigenvalue, invariants over the remaining affine range). Data `codeb/data/genb_*.json` (fields r, sg, rs, rv, sV, Ps, PV on four rays, integer v), logs `codeb/logs/`. Results: static error order 4.00; h_s changes 1.6e-8 (r); blow-up v_b = 252, 307, 364, 420, 477 for h_v = 0.2 ... 0.0125 (shift 56.6 = 4 ln2/kappa_+ per halving); agreement with code A (hs->0, Romberg): 1e-7 in r, 4e-6 (absolute) in sigma_v for 120<=v<=240 (after the 1.6e-4 hs correction); unconstrained version (proj=0) non-finite at v=70, 95, 112 for h_v=0.1, 0.05, 0.025.
11. Reduction check (`lift_check_4d.py`, `logs/lift_check_4d.log`): 4D Riemann tensor from random spherical metrics by finite differences; Zakhary-McIntosh invariants; the lifts P, H, T, K of arXiv:2602.16773 Eqs. 55, 63-65 reproduce psi, eta, tau, calR to <=8e-11 (the shipped log also prints a negative control, first power of I_C3, which fails by 1e2-1e4; Eq. 65 needs I_C3^2 in its fourth term); GR density 2P-4H+K = R to 3e-13.

12. Mechanism of the window law, code E and its seed (`codee/`, Paper F Secs.
